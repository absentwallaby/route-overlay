# Route Overlay

Route Overlay is a client-only web app for placing a GPS route exported from Garmin Connect (`.gpx`, `.tcx`, or `.kml`) over a photo of a paper orienteering map. It lets you match points between the route and map, fine-tune the alignment, and export the completed overlay as a PNG.

Use the app at [www.route-on-map.com](https://www.route-on-map.com).

Contributions are welcome. Please open an issue or submit a pull request with improvements, fixes, or suggestions.
